Not specifically recommending any of these, and would not use any of these for anything sensitive (e.g. work-related)

- [All Online Tools in One Box | 10015 Tools](https://10015.io) - many webdev tools
- [All – Tiny Helpers](https://tiny-helpers.dev/) - hundreds of simple online tools for web developers
- [Convert your markdown files to PDF with our online converter for free!](https://www.markdowntopdf.com/) - says it all
- [Easy Markdown Tables with Table to Markdown · Table to Markdown](https://tabletomarkdown.com/) - convert tables from various sources to Markdown
- [Explainpaper](https://www.explainpaper.com/) - upload a PDF of a scientific paper and get AI to explain it to you
- [Free Online Tools for developers, testers, project managers, devops, and security testers | LambdaTest](https://www.lambdatest.com/free-online-tools) - many more tools
- [Free online tools - no registration, unlimited use](https://freetools.site/) - mainly format converters
- [Git Explorer](https://gitexplorer.com/) - find the Git command you need with this tool
- [GoOnlineTools.com - 100% Free Online Tools Collection](https://goonlinetools.com/) - lots (I mean lots) of webdev tools
- [HTML Cleaner - Online Beautifyer and Word Converter](https://html-cleaner.com/) - tidy up your HTML code (also JavaScript or CSS) online - might also be useful if you are learning HTML (as you should)
- [Have I Been Pwned: Check if your email has been compromised in a data breach](https://haveibeenpwned.com) - see if your login details for any online accounts are in the hands of hackers
- [Hemingway Editor](https://hemingwayapp.com/) - an online app to improve your writing
- [Mozilla SSL Configuration Generator](https://ssl-config.mozilla.org) - configure your nginx or other server software for encrypted connections
- [Online GIF Tools - Simple, free and easy to use GIF utilities](https://onlinegiftools.com/) - various GIF tools
- [Online Summarization Tool | PDF Summarizer | Summarize articles, text, documents with IntelliPPT](https://www.intellippt.com/#summarization) - summarise any text using AI
- [Paste to Markdown](https://euangoddard.github.io/clipboard2markdown/) - paste text into a Web page and see it converted to markdown
- [Phishing Incident Response Automation | Phish Report](https://phish.report) - check out a dodgy link in a phishing email
- [Prettify YAML - Online YAML Tools](https://onlineyamltools.com/prettify-yaml) - prettify YAML - lots of other YAML tools too
- [RSS Finder](https://rss-finder-web-app.vercel.app/) - find RSS feeds from a URL (might save you searching the source)
- [Redact PDF Free Online | PDF.online](https://pdf.online/redact-pdf): another PDF redaction tool - claims all to work in your browser - not recommended
- [Redact PDF Free: Secure Online PDF Redaction Tool | AvePDF](https://avepdf.com/redact-pdf) - redact a PDF online - am not recommending you use this for anything sensitive
- [Redirect Detective - Discover where those redirects really go to](https://redirectdetective.com) - another tool for looking at dodgy links
- [Text Fixer - Online Text Tools](https://www.textfixer.com/tools/) - various text, code and other tools
- [The best tools for web development | Web Code Tools](https://webcode.tools) - generate HTML and other code; even data
- [gitignore.io - Create Useful .gitignore Files For Your Project](https://www.toptal.com/developers/gitignore) - create the perfect `.gitignore` file
- [mmm.page — Dead Simple, Drag & Drop Websites](https://mmm.page/) - very easy and quick way to create your own website or blog
- [readme.so](https://readme.so/) - create the perfect README page for your GitHub/GitLab project using an online editor
